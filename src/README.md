# Source Code

This directory contains reusable Python scripts developed for the HIV-1 drug-resistance machine learning project.

## Planned Components

- `preprocessing.py` — Data loading, validation, cleaning, and preprocessing functions.
- Additional modules may be introduced for feature engineering, model development, and evaluation.

## Development Approach

Code will be organized into reusable functions to improve readability, maintainability, and reproducibility.

Scripts will be added as the research workflow develops.
