# Research Results

This directory will contain outputs generated during the analysis of HIV-1 genotype–phenotype data.

## Planned Outputs

- Exploratory data analysis visualizations.
- Data quality and preprocessing summaries.
- Machine learning model evaluation metrics.
- Confusion matrices and ROC curves, where appropriate.
- Feature importance and model interpretability visualizations.

## Research Integrity

Only results generated and verified during the project will be included.

Results will be documented with sufficient context to explain the methods used to generate them.

**Note:** This directory will be populated progressively as the research advances.
