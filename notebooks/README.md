# Research Notebooks

This directory contains Jupyter notebooks used for the computational analysis of HIV-1 genotype–phenotype data.

## Planned Workflow

1. `01_data_exploration.ipynb` — Initial dataset inspection and exploratory data analysis.
2. `02_data_cleaning.ipynb` — Data quality assessment and preprocessing.
3. `03_feature_engineering.ipynb` — Preparation of genetic and mutation-related features.
4. `04_model_training.ipynb` — Development of machine learning models.
5. `05_model_evaluation.ipynb` — Model validation and performance assessment.
6. `06_model_interpretability.ipynb` — Investigation of important predictive features.

## Computational Environment

The notebooks will primarily use Python and Google Colab.

## Reproducibility

Each notebook will include explanations, documented procedures, and outputs where appropriate to make the analysis understandable and reproducible.

**Note:** Notebooks will be added progressively as each research stage is completed.
